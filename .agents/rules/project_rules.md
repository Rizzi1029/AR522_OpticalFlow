# Project Rules

1. This is an academic Robot Vision project.
2. Do not change the agreed project architecture or research goals without explicit approval.
3. The primary optical-flow models are FlowNetS and RAFT.
4. The research direction is confidence-aware heterogeneous optical-flow fusion for dynamic hazard mapping and local robot path planning.
5. Never fabricate experimental results, metrics, plots, citations, or observations.
6. Do not delete datasets, checkpoints, outputs, reports, or source files without explicit approval.
7. Do not modify the Python, PyTorch, CUDA, or virtual-environment setup unnecessarily.
8. Prefer modular Python source files for core logic. Use notebooks mainly for experiments, visualization, and analysis.
9. Run relevant tests or verification commands after modifying core code.
10. Explain significant proposed changes before making them when they could affect the research methodology.
